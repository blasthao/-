# 🐻 狂暴战熊：末日救赎

**RAGE BEAR: DOOMSDAY REDEMPTION**

一款基于 HTML5 + Three.js 开发的浏览器端末日题材掩体射击小游戏。

玩家将扮演身穿战术装备的“狂暴战熊”，依托掩体抵御不断逼近的敌人，在废土、实验基地和最终决战中逐步揭开灾难背后的真相。

> 🎮 纯前端游戏 · 浏览器运行 · 无需安装  
> 💻 支持 Windows / macOS / Linux / 移动端浏览器

---

## 🎮 游戏特色

### 🛡️ 掩体射击

玩家以掩体为核心进行战斗。

通过探身、射击、回到掩体和换弹进行战术操作，在有限空间内应对不同距离和类型的敌人。

### 📖 故事模式

游戏包含完整的五关故事线：

1. **第一关：沦陷废土**
2. **第二关：病毒真相**
3. **第三关：人类实验产物**
4. **第四关：黑幕显露**
5. **第五关：决战幕后黑手**

随着关卡推进，逐渐揭开病毒灾难、人体实验以及外星势力背后的阴谋。

### ♾️ 无限肉鸽模式

除了故事模式，还提供无限轮回挑战。

每轮战斗结束后可以选择不同强化，持续提升角色能力并挑战更高难度。

### 🔫 多种武器

游戏包含多种武器系统：

- VECTOR
- S1897
- M4A1
- RPG-7
- 空袭支援

不同武器具有不同的射速、伤害、弹药和战斗方式。

### 🎯 战术装备

战斗过程中可以获得并使用：

- 🩹 急救箱
- 🧪 无敌药剂
- 🤖 自动炮台
- ✈️ 空袭支援

合理使用装备可以提高战场生存能力。

### 👹 多类型敌人与 Boss

不同关卡拥有不同敌人和 Boss。

敌人具有不同的移动、攻击和战斗机制，部分 Boss 拥有特殊弱点、护盾或特殊攻击机制。

### 🏆 全球排行榜

游戏支持全球战绩排行榜。

无限模式下可以记录击杀成绩，并通过 Supabase 进行云端排行榜同步；网络不可用时也可以使用本地缓存作为备用。

---

## 🕹️ 操作方式

### PC

- **鼠标按住 / 操作区域**：探身并攻击
- **鼠标操作**：进行战斗操作
- **武器栏**：切换武器
- **暂停按钮**：暂停游戏

### 移动端

游戏针对触摸操作进行了适配。

按住屏幕进行探身攻击，松开后回到掩体状态。
